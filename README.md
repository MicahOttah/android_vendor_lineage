# android_vendor_lineage

Fork of `LineageOS/android_vendor_lineage` for the **LG G Pad X 8.0 (V521)**
LineageOS 15.1 port.  The port builds from `lineage-15.1-v521`; the other
branches are upstream.

Changes:

* `WITH_ADB_INSECURE=true` builds without adb authorisation (as in
  lineage-16.0).  Other devices are unaffected.

Port and device tree: <https://github.com/MicahOttah/android_device_lge_v521>
